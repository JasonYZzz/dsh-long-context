Mode: Operate. This is an extension of the incumbent DSH interface. Preserve native typography, surface tokens, focus behavior, controls and user theme.

THESIS: Make document workflows inspectable and recoverable from the conversation header.
OWN-WORLD: Existing DSH foreground, muted foreground, surface and border CSS variables; native React primitives and system body text.
STORY: Choose a workspace-backed Long Context session, import a document, create a task, inspect progress, advance bounded steps and export a candidate.

FORM: Native operating panel with stacked labeled forms and compact task rows; this preserves the host rather than selecting a new visual world. Seed is not applicable to this incumbent extension.
