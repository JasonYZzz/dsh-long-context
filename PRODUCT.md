# Product

## Platform
web

## Users
DSH Web users editing long scientific documents, screening literature and generating documents with chapter context.

## Product Purpose
Expose the existing evidence-bound long-document tools inside the user's native DSH Web, with recoverable tasks and preserved original files.

## Stack
Existing TypeScript Cordis host; native DSH React client module and UI primitives. No separate frontend framework or external control server.

## Capabilities and Constraints
The user authorized installation on port 3080, removal of both Context Pro packages, and service restart. npm publication is deferred by the user's latest answer. Exact editing and 30-page model generation have automated evidence; scientific semantic completeness and 51-paper real quotas remain experimental.

## Operating Context
Workspace-backed Long Context sessions. Host authentication, filesystem policy, scoped tools, task ownership and ledger revisions remain authoritative. Preserve other installed plugins and credentials.
